# 🌟 LifeForge

LifeForge is a browser-based life simulation game inspired by the life simulator genre, built from scratch using HTML, CSS, JavaScript, and JSON. Every new life is unique, with randomly generated families, careers, events, relationships, and choices that shape your story.

## Features

* 👤 Create a unique character
* 🎲 Randomly generated lives
* 👨‍👩‍👧 Family system with parents and siblings
* ❤️ Relationships, dating, marriage, and children
* 🎓 Education from preschool to university
* 💼 Hundreds of careers
* 💰 Money, banking, investments, and businesses
* 🚗 Buy houses, cars, and other assets
* 🏆 300+ unlockable badges
* 📜 Thousands of random events loaded from JSON
* 😊 Character stats (Health, Happiness, Intelligence, Looks, Fame, Karma, Stress, and more)
* 💾 Automatic save with Local Storage
* 🌙 Dark modern interface
* 📱 Responsive design for desktop and mobile

## Technologies

* HTML5
* CSS3
* JavaScript (ES6)
* JSON
* Local Storage API



## Installation

1. Download or clone the project.
2. Open the project folder.
3. Run it using a local web server (recommended), or open `index.html` in your browser.
4. Start your first life!

## Save System

Your progress is automatically saved in your browser using Local Storage.

Saved data includes:

* Character
* Family
* Relationships
* Careers
* Money
* Inventory
* Badges
* Achievements
* Settings
